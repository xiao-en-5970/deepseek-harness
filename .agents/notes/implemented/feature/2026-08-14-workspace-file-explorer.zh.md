# Agent Note: Web 工作区文件浏览器

Status: implemented

[English](2026-08-14-workspace-file-explorer.md) | 中文

## Problem

Web 工作区选择器可以登记目录，但没有持续显示的文件树、常规文件和目录创建、直接下载，也缺少在已选工作区内便捷上传文件夹的入口。

## Decision

Web 应用在桌面布局右侧常驻可伸缩文件浏览器，并在手机布局中提供全屏面板。它列出当前工作区，创建文件和目录，以有界批次上传文件或文件夹，并通过限制在已登记工作区内的 Host API 下载文件或生成的目录压缩包。

所有 Host 路径操作都解析到所选工作区下，拒绝路径穿越和符号链接逃逸，并在完整结果位置执行请求与压缩包限制。上传保留相对路径，逐项报告冲突，不隐式覆盖已有文件。

## Alternatives considered

**仅复用工作区选择器。** 选择器只能选择根目录，无法支持持续浏览和文件操作。

**暴露任意 Host 路径。** 直接浏览 Host 会绕过工作区限制和租户预期。

**所有操作都要求命令行。** 纯 Shell 流程无法覆盖浏览器上传和手机使用场景。

## Consequences

用户无需离开对话即可管理当前工作区，同一 API 同时支持桌面和手机布局。目录下载需要有界压缩包生成，大型上传会拆成多次请求，而不是发送一个超大载荷。
